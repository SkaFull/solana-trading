## 項目簡介

SOL 管理系統是一個面向 Solana 区塊鏈的全功能管理與自動化交易平台。系統集成了 **鏈上錢包管理、多策略自動化交易、多 DEX 聚合、NFT 鑄造、MEV 防護、實時行情監控**等核心能力。

**核心亮點：**

- 🚀 **7 種交易策略**：覆蓋上漲、下跌、震蕩、保本等全部市場場景
- 🔫 **Meteora 狙擊機器人**：基於 gRPC Stream 實時監聽新池子，Jito Bundle 極速搶跑
- 🏦 **多層級錢包體系**：主錢包 → 子錢包 → 持倉錢包，支持批量發散/歸集
- 🛡️ **Jito MEV 防護**：所有交易通過 Jito Block Engine 發送，防止搶跑
- 🔗 **多 DEX 聚合**：Meteora · Jupiter · Pump.fun · Raydium 一站式交易
- 🎨 **NFT 全流程**：基於 Metaplex 標準的鑄造與元數據管理

## 核心功能

### 1. 自動化交易引擎

系統核心模塊，支持基於策略的全自動代幣買賣。

#### 七種交易策略

| 策略模式 | 适用場景 | 策略邏輯 |
|----------|----------|----------|
| **平穩模式** | 市場窄幅震蕩 | 中性交易策略，小倉位高拋低吸 |
| **緩慢上漲模式** | 價格溫和上行 | 渐進式分批買入，動態調整倉位 |
| **快速上漲模式** | 價格快速拉升 | 追漲策略，快速建倉跟隨趨勢 |
| **緩慢下跌模式** | 價格逐步回落 | 階梯式止損，逐步減少敞口 |
| **快速下跌模式** | 價格急速暴跌 | 緊急賣出策略，保護本金安全 |
| **保本模式** | 高不确定性市場 | 保守策略，優先保證本金安全 |
| **持倉模式** | 長期持有場景 | 維持當前持倉，僅監控不操作 |

#### 交易引擎特性

- **多策略並行調度**：多個策略同時運行，獨立配置互不干擾
- **批量交易執行**：高並發批量構建和發送交易，支持队列管理
- **智能速率限制**：自動控制 RPC 調用頻率，防止節點過載
- **錢包冷卻機制**：同一錢包交易間隔控制，避免鏈上操作沖突
- **交易預模擬**：發送前模擬執行，降低失敗率
- **Jito Bundle 支持**：通過 Jito Block Engine 發送，防止 MEV 搶跑
- **可配置滑點**：靈活設置滑點容忍度
- **優先級費用**：支持 Compute Unit 優先級費用，確保快速上鏈

#### 支持的路由類型

| 路由 | 說明 |
|------|------|
| Jupiter 聚合器 | 全鏈最优路徑聚合交易 |
| Meteora | 自動識別 DammV2 / DBC 池子類型 |
| Pump.fun / PumpSwap | Pump 生態完整支持（含做空） |
| Raydium | v1 / v2 雙版本兼容 |
| GMGN | 高效交易路由 |

### 2. 錢包管理體系

#### 三層錢包架構

```
主錢包 (Master)
  ├── 子錢包群 (Sub Wallets)       ← 分散化交易，降低關聯風險
  ├── 持倉錢包 (Holding Wallets)   ← 長期倉位管理
  └── 配置錢包 (Config Wallets)    ← 特殊場景專用
```

#### 錢包核心功能

| 功能 | 說明 |
|------|------|
| 創建/更換主錢包 | 安全生成密鑰對，私鑰加密存儲 |
| 批量創建子錢包 | 一鍵生成大量交易錢包 |
| SOL 發散/歸集 | 主錢包 ↔ 子錢包批量轉賬（隨機金額防追蹤） |
| Token 發散/歸集 | 代幣在主錢包與子錢包間批量流轉 |
| 批量轉賬 | 高效並發 SOL 轉賬 |
| 實時余額查詢 | 鏈上 SOL 和 SPL Token 余額實時獲取 |
| 子錢包回收 | 關閉賬戶並回收 SOL 租金 |

### 3. 多 DEX 集成

#### Meteora（深度集成）

| 池子類型 | 支持功能 |
|----------|----------|
| **DammV2** (Dynamic AMM v2) | 池子查詢、買賣交易、流動性管理 |

- 低滑點大額交易支持

#### Pump.fun / PumpSwap

## 交易流程

### 整體交易流水線

```
用戶發起交易
    │
    ▼
策略調度器           ← 匹配策略模式，獲取子錢包列表
    │
    ├─ 常規交易輪次  ← 策略模式 1-6
    └─ 倉交易輪次  ← 策略模式 7
         │
         ▼
批量執行器           ← 並發構建買賣交易
    │
    ├─ Jupiter 路由  ← 聚合最优路徑
    ├─ Meteora 路由  ← 自動識別 DammV2 / DBC
    ├─ Pump.fun 路由 ← Pump 生態交易
    ├─ Raydium 路由  ← v1 / v2 兼容
    └─ GMGN 路由     ← 高效交易路由
    │
    ▼
Jito Block Engine    ← Bundle 發送，MEV 防護
    │
    ▼
結果記錄 & 自動賣出   ← 盈亏監控，止盈止損
```

### 交易構建步驟

1. **解密私鑰** — 從安全存儲中解密錢包 Keypair
2. **獲取 Blockhash** — 從 RPC 獲取最新区塊哈希
3. **選擇路由** — 根據配置選擇最优交易路由
4. **獲取報價** — 查詢最优路徑和實時報價
5. **構建交易** — 生成待簽名交易對象
6. **設置優先費** — 可選的 Compute Unit Price
7. **簽名** — 使用解密后的私鑰簽名
8. **模擬驗證** — 發送前模擬執行，確認可行性
9. **發送上鏈** — 通過 Jito Bundle 或直接 RPC 發送

## 快速開始

### 環境要求

- **Node.js** >= 16
- **MySQL** >= 5.7
- **Redis** >= 5.0
- **Solana Mainnet RPC** 節點

### 前端啟動

```bash
# 安裝依賴
npm install

# 啟動開發服務
npm run dev
```

### Solana 后端啟動

```bash
# 進入 Solana 模塊
cd src/api/sol

# 安裝依賴
npm install

# 配置 .env 文件（數據庫、RPC 等必要參數）

# 啟動服務
node solana.js

# 生產環境推薦 PM2
pm2 start solana.js --name sol-backend
```
