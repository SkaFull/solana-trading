## 项目简介

SOL 管理系统是一个面向 Solana 区块链的全功能管理与自动化交易平台。系统集成了 **链上钱包管理、多策略自动化交易、多 DEX 聚合、NFT 铸造、MEV 防护、实时行情监控**等核心能力。

**核心亮点：**

- 🚀 **7 种交易策略**：覆盖上涨、下跌、震荡、保本等全部市场场景
- 🔫 **Meteora 狙击机器人**：基于 gRPC Stream 实时监听新池子，Jito Bundle 极速抢跑
- 🏦 **多层级钱包体系**：主钱包 → 子钱包 → 持仓钱包，支持批量发散/归集
- 🛡️ **Jito MEV 防护**：所有交易通过 Jito Block Engine 发送，防止抢跑
- 🔗 **多 DEX 聚合**：Meteora · Jupiter · Pump.fun · Raydium 一站式交易
- 🎨 **NFT 全流程**：基于 Metaplex 标准的铸造与元数据管理

## 核心功能

### 1. 自动化交易引擎

系统核心模块，支持基于策略的全自动代币买卖。

#### 七种交易策略

| 策略模式 | 适用场景 | 策略逻辑 |
|----------|----------|----------|
| **平稳模式** | 市场窄幅震荡 | 中性交易策略，小仓位高抛低吸 |
| **缓慢上涨模式** | 价格温和上行 | 渐进式分批买入，动态调整仓位 |
| **快速上涨模式** | 价格快速拉升 | 追涨策略，快速建仓跟随趋势 |
| **缓慢下跌模式** | 价格逐步回落 | 阶梯式止损，逐步减少敞口 |
| **快速下跌模式** | 价格急速暴跌 | 紧急卖出策略，保护本金安全 |
| **保本模式** | 高不确定性市场 | 保守策略，优先保证本金安全 |
| **持仓模式** | 长期持有场景 | 维持当前持仓，仅监控不操作 |

#### 交易引擎特性

- **多策略并行调度**：多个策略同时运行，独立配置互不干扰
- **批量交易执行**：高并发批量构建和发送交易，支持队列管理
- **智能速率限制**：自动控制 RPC 调用频率，防止节点过载
- **钱包冷却机制**：同一钱包交易间隔控制，避免链上操作冲突
- **交易预模拟**：发送前模拟执行，降低失败率
- **Jito Bundle 支持**：通过 Jito Block Engine 发送，防止 MEV 抢跑
- **可配置滑点**：灵活设置滑点容忍度
- **优先级费用**：支持 Compute Unit 优先级费用，确保快速上链

#### 支持的路由类型

| 路由 | 说明 |
|------|------|
| Jupiter 聚合器 | 全链最优路径聚合交易 |
| Meteora | 自动识别 DammV2 / DBC 池子类型 |
| Pump.fun / PumpSwap | Pump 生态完整支持（含做空） |
| Raydium | v1 / v2 双版本兼容 |
| GMGN | 高效交易路由 |

### 2. 钱包管理体系

#### 三层钱包架构

```
主钱包 (Master)
  ├── 子钱包群 (Sub Wallets)       ← 分散化交易，降低关联风险
  ├── 持仓钱包 (Holding Wallets)   ← 长期仓位管理
  └── 配置钱包 (Config Wallets)    ← 特殊场景专用
```

#### 钱包核心功能

| 功能 | 说明 |
|------|------|
| 创建/更换主钱包 | 安全生成密钥对，私钥加密存储 |
| 批量创建子钱包 | 一键生成大量交易钱包 |
| SOL 发散/归集 | 主钱包 ↔ 子钱包批量转账（随机金额防追踪） |
| Token 发散/归集 | 代币在主钱包与子钱包间批量流转 |
| 批量转账 | 高效并发 SOL 转账 |
| 实时余额查询 | 链上 SOL 和 SPL Token 余额实时获取 |
| 子钱包回收 | 关闭账户并回收 SOL 租金 |

### 3. 多 DEX 集成

#### Meteora（深度集成）

| 池子类型 | 支持功能 |
|----------|----------|
| **DammV2** (Dynamic AMM v2) | 池子查询、买卖交易、流动性管理 |
| **DBC** (Dynamic Bonding Curve) | 联合曲线池子的交易与流动性操作 |
| **统一交易入口** | 自动识别池子类型，智能路由 |
| **价格查询** | 实时从 Meteora 池子获取代币价格 |

#### Jupiter

- 聚合器报价查询，获取全链最优交易路径
- 低滑点大额交易支持

#### Pump.fun / PumpSwap

- Pump.fun 代币报价与快速交易
- PumpSwap 流动性管理（添加/移除/检查）
- PumpSwap 做空支持

## 交易流程

### 整体交易流水线

```
用户发起交易
    │
    ▼
策略调度器           ← 匹配策略模式，获取子钱包列表
    │
    ├─ 常规交易轮次  ← 策略模式 1-6
    └─ 持仓交易轮次  ← 策略模式 7
         │
         ▼
批量执行器           ← 并发构建买卖交易
    │
    ├─ Jupiter 路由  ← 聚合最优路径
    ├─ Meteora 路由  ← 自动识别 DammV2 / DBC
    ├─ Pump.fun 路由 ← Pump 生态交易
    ├─ Raydium 路由  ← v1 / v2 兼容
    └─ GMGN 路由     ← 高效交易路由
    │
    ▼
Jito Block Engine    ← Bundle 发送，MEV 防护
    │
    ▼
结果记录 & 自动卖出   ← 盈亏监控，止盈止损
```

### 交易构建步骤

1. **解密私钥** — 从安全存储中解密钱包 Keypair
2. **获取 Blockhash** — 从 RPC 获取最新区块哈希
3. **选择路由** — 根据配置选择最优交易路由
4. **获取报价** — 查询最优路径和实时报价
5. **构建交易** — 生成待签名交易对象
6. **设置优先费** — 可选的 Compute Unit Price
7. **签名** — 使用解密后的私钥签名
8. **模拟验证** — 发送前模拟执行，确认可行性
9. **发送上链** — 通过 Jito Bundle 或直接 RPC 发送

## 快速开始

### 环境要求

- **Node.js** >= 16
- **MySQL** >= 5.7
- **Redis** >= 5.0
- **Solana Mainnet RPC** 节点

### 前端启动

```bash
# 安装依赖
npm install

# 启动开发服务
npm run dev
```

### Solana 后端启动

```bash
# 进入 Solana 模块
cd src/api/sol

# 安装依赖
npm install

# 配置 .env 文件（数据库、RPC 等必要参数）

# 启动服务
node solana.js

# 生产环境推荐 PM2
pm2 start solana.js --name sol-backend
```

## 注意事项

1. **私钥安全**：所有私钥采用 AES-256-CBC 加密后存储，密钥定期轮换
2. **RPC 限流**：系统内置速率限制器，自动控制调用频率
3. **Jito 服务**：使用 Jito Bundle 需购买相应套餐
4. **生产部署**：推荐 PM2 管理进程，配置自动重启和日志轮转
5. **安全通信**：生产环境务必启用 HTTPS 和 WSS
